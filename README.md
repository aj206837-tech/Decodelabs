# ☕ Brew & Bliss - Interactive Coffee Shop Webpage

Welcome to the repository for **Brew & Bliss**, a responsive, modern coffee shop interactive landing page built as part of **DecodeLabs Project 3 (Interactive Web Elements)**. 

This project goes beyond a static design by implementing pure client-side interaction through the JavaScript DOM (Document Object Model) and capturing the real-time needs of a modern user interface.

---

## 🚀 Features

- **Dynamic Theme Switcher (Dark/Light Mode):** A seamless user experience toggle that changes the color tokens across the page dynamically without modifying the layout core.
- **Responsive Navigation:** A customized slide-out mobile menu using a modern hamburger icon built from scratch with pure CSS and JavaScript.
- **Beautiful Typography & Layout:** Built using modern serif and elegant cursive typography to match the premium aesthetics of a high-end cafe.
- **Professional Footer Structure:** Fully organized with quick links, working hours, active branding logo, and vector social media icons with modern hover micro-interactions.

---

## 🛠️ Tech Stack & Architecture

- **Structure:** Semantic HTML5
- **Styling:** CSS3 (Flexbox, Media Queries, Custom CSS Properties)
- **Behavior:** Vanilla JavaScript (ES6+ Standard)
- **Icons:** Font Awesome v6 (CDN Integration)

### Architectural Standards Applied:
- **Decoupled States:** Followed standard training kit rules by separation of styling classes from state management classes (`active`, `dark-mode`, etc.).
- **Volatile DOM Manipulation:** Directly changing values safely using native attributes and methods.
